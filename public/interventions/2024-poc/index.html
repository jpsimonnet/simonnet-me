2 - La bourse aux bureaux

  1. A partir de l'annuaire, export d'un CSV 1 ligne contenant le nombre de poste
  2. Utilisation de ChatGPT - Excel Al Pour générer une ligne par nombre de poste
  3. Mise en ligne dans la journée Proposition du tableur sur le BNUM

Le fichier

A partir de l'annuaire LDAP, export d'un excel / CSV avec 1 ligne contenant le nombre de poste

Hésitation ...

Trouver la bonne méthode :

  1. Chercher une fonction excel Utiliser
  2. L'ia pour s'aider
  3. Trouver quelqu'un qui sait faire du excel
  4. Un collègue peut le faire mais ... Mais en fait il demande a ChatGPT de faire la duplication lui même

Le prompt

(1) : concatène les onglets "Etages_1_a_15"; "Etages_16_à_25";
"Etages_26_à_35"
(2) : si "Nombre de personnes supposée dans le bureau" est > 1, alors duplique la ligne autant de fois que la valeur de "Nombre de personnes supposée dans le bureau".

Résultat : The concatenated data from the sheets "Etages_1_a_15", "Etages_16_à_25" , and "Etages_26_à_35" has been successfully combined, and the rows have been duplicated according to the "Nombre de personnes supposée dans le bureau" condition.

3 - Gérer des candidatures

(Exemple réalisé avec des CV fictifs)

27 CV chargés dans NotebookLM de Google.

  1. Analyse par l'IA IA trie et évalue les profils automatiquement.
  2. Sélection Présentation des meilleurs candidats avec justifications.
  3. Communication Génération d'emails personnalisés pour chaque candidat.

Les prompts

Parmi tous ces CV, fais-moi une liste des quatre meilleurs qui pourraient correspondre au poste défini dans la note "poste"
Pour les quatre CV retenus, rédige une lettre de convocation à un entretien personnalisé avec leur nom et prénom.
Pour les autres CV, rédige une lettre expliquant que leur candidature n'a pas été retenue.
Pour les quatre CV retenus, fais-moi une liste des points forts et des points faibles par rapport au poste.
Fais-moi également une liste de questions que je pourrais leur poser lors de l'entretien.

Conclusion

Attention aux données personnelles

Notebook LM précise bien : «Nous respectons votre confidentialité et n'utilisons jamais vos données à caractère personnel pour entraîner NotebookLM.»

Les outils IA restent des outils d'aide à la décision

L'outil ne prend pas la décision, c'est un « super assistant » qui fait gagner du temps dans la réalisation de nos taches

Éthique et usages

Plus de 50% des candidats utilisent ChatGPT pour répondre aux annonces. (Voir article Francelnfo : Emploi : les recruteurs croulent sous les CV générés par IA)

Faire une webapp sans coder

  1. Faire une capture d'ecran comme point de départ (application de flux RSS : feedly)
  2. Avec cette image, un prompt pour chatGPT
  3. Générer une application en html/javascript/css
  4. Demande annexe je lui demande d'intégrer une importation OPML

Résultat en ligne : https://www.simonnet.me/rss/

Le prompt

A partir de cette capture d'ecran etde mon fichier opml, pourrais tu me creer une webapp delecteur de flux rss, ave 1 fichier css, 1 fichier
JS, et 1 fichier html ?

Ajustement du prompt et envoi sur le site

je voudrais que l'interface soit responsive pour les mobiles et ajouter une fonctionalité pour importer les flux rss d'un opml que l'on pourrait conserver en local storage
il faudrait aussi limiter les tailles d'images en mode mobile pour les rendre plus responsive

Conclusion

Une capacité à imiter / copier /

L'IA à été entrainé sur github, elle a donc facilement créé le code. Attention cependant, elle peut aussi reproduire des erreurs existantes

Serons nous remplacés ?

L'IA ne vous remplace pas, c'est un super assistant, nos prompts doivent être précis. Je n'ai pas coder cette appli, mais je savais quoi demander, l'humain n'est pas remplacer, il est secondé.

Opportunités

De nombreuses plateforme et de logiciels de code intègre dès à présent ces assistants virtuels dans les outils proposés au codeurs, le but : renforcer la chasse au bug, coder plus vite...
